# Architecture decision records

We record significant decisions using [Michael Nygard's format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions): context, decision, status, and consequences. To change a decision, add a new ADR that supersedes the old one; do not rewrite history.
